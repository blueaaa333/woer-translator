# 本机数据与联网行为

查词从本地词库读取。可选语音在独立的本地 Piper 进程内合成，查询词通过进程标准输入传递，不发送给网络服务。

只有用户点击“来源”时才打开浏览器的公开词典页面。安装脚本从 PyPI、GitHub 或 Hugging Face 下载依赖；这些服务会收到正常的下载请求信息。

应用在 `%LOCALAPPDATA%\QingCi` 保存：偏好设置、生词本、合成音频缓存、故障日志和划词响应日志。响应日志包含进程名、进程/窗口标识符、事件序号和时序；不记录所选文字、查询词或网页地址。发生异常时的堆栈可能包含本机路径。

划词监听使用本机鼠标/键盘事件判断是否显示工具条。仅点击“查词 / 发音 / 复制”或主动使用查询快捷键后，才对原窗口执行一次复制，读取所选 Unicode 文字；会替换当前剪贴板文字，不读取或备份整份剪贴板格式。扫描图片不能取词。

退出应用会停止其监听与语音子进程。`×` 和 `Esc` 只收起窗口；请使用“··· → 退出应用”。

发布仓库不含上述用户数据。报告问题时请只提供必要的复现步骤，检查日志后再主动分享。
