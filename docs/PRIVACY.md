# 本机数据与联网行为

Mac 版的系统监听、剪贴板检查和明确点击后的选词复制由本机独立辅助进程完成，通过仅继承给该子进程的私有本地套接字与界面通信，不开放网络端口。辅助进程异常类型写入本机 `mac-native-errors.log`，不自动上传。

查词从本地词库读取。Windows 可选语音在独立的本地 Piper 进程内合成；Mac 通过系统 say 在本机合成。本地合成的查询词仅通过进程标准输入传递。v0.3.3 起优先真人录音默认开启：点击发音，或开启自动朗读后查词，会将当前英文查询词发送给 Wikimedia Commons API 并按需下载录音；对方会收到该词、User-Agent 和正常连接信息，不发送页面全文、生词本或日志。同一词和口音缓存后可离线播放；“··· → 优先真人发音（联网）”可关闭此功能。仅选中而未查询或播放不会请求音频。录音作者、许可及原始文件页随缓存保存在本机，可从“发音来源与许可”查看。

只有用户点击“来源”时才打开浏览器的公开词典页面。自 v0.3.0 起，软件默认在启动后及运行期间每天检查一次 GitHub 正式发行版本；可在“··· → 自动检查更新”关闭。检查会向 GitHub 发送当前应用版本的 User-Agent 和正常连接信息，不包含查询词、生词本、剪贴板或本机日志。只有点击“下载更新”才下载安装包，SHA-256 校验后再由用户点击“重启并更新”。安装脚本从 PyPI、GitHub 或 Hugging Face 下载依赖；这些服务会收到正常的下载请求信息。

更新包、续传文件和安装记录保存在上述用户数据目录的 updates 子目录。更新不清除 Mac 隔离标记或绕过系统授权；Apple 系统确认与权限开关仍由用户自行处理。

应用在 Windows 的 `%LOCALAPPDATA%\QingCi` 或 Mac 的 `~/Library/Application Support/WoerTranslator` 保存：偏好设置、生词本、合成音频缓存、故障日志和划词响应日志。响应日志包含进程名、进程/窗口标识符、事件序号和时序；不记录所选文字、查询词或网页地址。发生异常时的堆栈可能包含本机路径。卸载程序不会主动删除这些用户数据。

划词监听使用本机鼠标/键盘事件判断是否显示工具条。仅点击“查词 / 发音 / 复制”或主动使用查询快捷键后，才对原窗口执行一次复制，读取所选 Unicode 文字；会替换当前剪贴板文字，不读取或备份整份剪贴板格式。扫描图片不能取词。

Mac 的辅助功能与输入监控权限仅用于上述本机交互，由用户在系统设置中决定。应用不会绕过授权；没有权限时可手动输入或使用主动复制查词。

退出应用会停止其监听与语音子进程。`×` 和 `Esc` 只收起窗口；请使用“··· → 退出应用”。

发布仓库不含上述用户数据。报告问题时请只提供必要的复现步骤，检查日志后再主动分享。


## 在线词典

在线维基词典默认开启，可从菜单关闭。明确查询后，单词或短语会发送给 zh.wiktionary.org；中文未收录时再发送给 en.wiktionary.org。对方会接收到网络请求所需的信息（包括 IP）。不发送页面全文、其他剪贴板内容或私人词库。查询缓存仅保存在当前用户的数据目录，不上传到本项目。
