# 隐私与网络行为

选中时观察鼠标手势，并在本机读取有限的辅助功能选区范围和文字以确认是否显示工具条；点击查词、快捷键查询或手动搜索后才进行词典查询。不会上传整个网页、剪贴板历史或私人词库。

- 在线维基词典默认开启，可从菜单关闭。明确查询后，当前词或短语发送给 zh.wiktionary.org；中文未收录时再发送给 en.wiktionary.org。对方会接收到网络请求所需的信息，包括 IP。
- 真人发音开启时，当前查询词会用于 Wikimedia Commons 的录音查询；下载保留逐文件署名，缓存只在本机。
- 可选离线发音包由用户主动从固定上游地址下载。音色权重不随公开安装包分发。
- 软件可自动检查 GitHub 新版，用户可以关闭。更新及语音下载请求会向对应服务器暴露通常的连接信息。
- 本地短语机器翻译默认关闭；启用后只连接本机 127.0.0.1:5000 的自托管 LibreTranslate 服务。
- 用户偏好、生词本、在线词典与音频缓存保存在当前用户目录，不提交到 GitHub；卸载默认保留。

不提供“绝无网络请求”或“完全匿名”的保证。没有接入聊天账户、浏览器登录凭据或 GPT API 密钥。


## 工具条选区确认（v0.3.12）

为防误弹，工具条显示前会本地检查辅助功能选区范围、位置和最多80字符的选词有效性；不为检测而模拟复制键，不读取页面全文，不发送网络查询。复制触发时，会将当前可访问的选区文字与已复制内容作本地比较，避免错误沿用后台写入的剪贴板文字。检测进程有超时和父进程生命周期限制。明确点击查词后才进行词典查询。应用没有提供可靠选区状态时不会自动弹条。

## v0.3.14 浏览器兼容

Windows 增加只读 IAccessible2 选区检查，与 UI Automation 互补；仍只读取最多80字符的实际选区及其坐标。不模拟复制来检测选区。用户实际按 Ctrl+C／Ctrl+Insert 后，若同一前台窗口在1.5秒内产生新的有效英文剪贴板文字，可显示查询工具条，不强制依赖 PDF 的辅助功能接口。只观察按键和剪贴板版本变化，不保存剪贴板历史。检测日志只记录请求编号、是否成功、超时或接口状态，不记录词或页面内容。
