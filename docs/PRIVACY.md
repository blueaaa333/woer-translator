# 本机数据与联网行为

Mac 版的系统监听、剪贴板检查和明确点击后的选词复制由本机独立辅助进程完成，通过仅继承给该子进程的私有本地套接字与界面通信，不开放网络端口。辅助进程异常类型写入本机 `mac-native-errors.log`，不自动上传。

查词从本地词库读取。Windows 可选语音在独立的本地 Piper 进程内合成；Mac 通过系统 say 在本机合成。查询词通过进程标准输入传递，不发送给网络服务。

只有用户点击“来源”时才打开浏览器的公开词典页面。安装脚本从 PyPI、GitHub 或 Hugging Face 下载依赖；这些服务会收到正常的下载请求信息。

应用在 Windows 的 `%LOCALAPPDATA%\QingCi` 或 Mac 的 `~/Library/Application Support/WoerTranslator` 保存：偏好设置、生词本、合成音频缓存、故障日志和划词响应日志。响应日志包含进程名、进程/窗口标识符、事件序号和时序；不记录所选文字、查询词或网页地址。发生异常时的堆栈可能包含本机路径。卸载程序不会主动删除这些用户数据。

划词监听使用本机鼠标/键盘事件判断是否显示工具条。仅点击“查词 / 发音 / 复制”或主动使用查询快捷键后，才对原窗口执行一次复制，读取所选 Unicode 文字；会替换当前剪贴板文字，不读取或备份整份剪贴板格式。扫描图片不能取词。

Mac 的辅助功能与输入监控权限仅用于上述本机交互，由用户在系统设置中决定。应用不会绕过授权；没有权限时可手动输入或使用主动复制查词。

退出应用会停止其监听与语音子进程。`×` 和 `Esc` 只收起窗口；请使用“··· → 退出应用”。

发布仓库不含上述用户数据。报告问题时请只提供必要的复现步骤，检查日志后再主动分享。
