# 隐私与网络行为

选中时观察鼠标手势，并在本机读取有限的辅助功能选区范围和文字以确认是否显示工具条；点击查词、快捷键查询或手动搜索后才进行词典查询。不会上传整个网页、剪贴板历史或私人词库。

- 在线维基词典默认开启，可从菜单关闭。明确查询后，当前词或短语发送给 zh.wiktionary.org；中文未收录时再发送给 en.wiktionary.org。对方会接收到网络请求所需的信息，包括 IP。
- 真人发音开启时，当前查询词会用于 Wikimedia Commons 的录音查询；下载保留逐文件署名，缓存只在本机。
- 可选离线发音包由用户主动从固定上游地址下载。音色权重不随公开安装包分发。
- 软件可自动检查 GitHub 新版，用户可以关闭。更新及语音下载请求会向对应服务器暴露通常的连接信息。
- 本地短语机器翻译默认关闭；启用后只连接本机 127.0.0.1:5000 的自托管 LibreTranslate 服务。
- 用户偏好、生词本、在线词典与音频缓存保存在当前用户目录，不提交到 GitHub；卸载默认保留。

不提供“绝无网络请求”或“完全匿名”的保证。没有接入聊天账户、浏览器登录凭据或 GPT API 密钥。


## 工具条选区确认（v0.3.12）

为防误弹，工具条显示前会本地检查辅助功能选区范围、位置和最多80字符的选词有效性；默认不为检测而模拟复制键（可选的自动复制兼容例外见下文），不读取页面全文，不发送网络查询。复制触发时，会将当前可访问的选区文字与已复制内容作本地比较，避免错误沿用后台写入的剪贴板文字。检测进程有超时和父进程生命周期限制。明确点击查词后才进行词典查询。应用没有提供可靠选区状态时不会自动弹条。

## v0.3.14 浏览器兼容

Windows 增加只读 IAccessible2 选区检查，与 UI Automation 互补；仍只读取最多80字符的实际选区及其坐标。不模拟复制来检测选区。用户实际按 Ctrl+C／Ctrl+Insert 后，若同一前台窗口在1.5秒内产生新的有效英文剪贴板文字，可显示查询工具条，不强制依赖 PDF 的辅助功能接口。只观察按键和剪贴板版本变化，不保存剪贴板历史。检测日志只记录请求编号、是否成功、超时或接口状态，不记录词或页面内容。

## v0.3.15 源应用已复制的选词

选词手势只记录源窗口、鼠标位置、剪贴板版本号和时间。若浏览器自身或其配套划词功能已完成复制，且700毫秒内的新文字归同一前台源进程所有，可用这份本地证据显示工具条，不额外模拟按键或改变剪贴板。证据只能使用一次；不保存剪贴板文字或历史。禁用“复制显示浮条”不会启用普通剪贴板通知，选中显示仍需上述条件或辅助功能选区确认。

## v0.3.16 Edge PDF 自动复制兼容（默认关闭）

用户可以在菜单主动启用“Edge PDF 自动复制取词”。启用后，仅在同一前台 msedge 进程、窗口标题包含 .pdf、用户已松开鼠标及修饰键、原选词手势未取消的情况下，发送一次 Ctrl+C。只有剪贴板版本变化、文字格式有效且剪贴板归该源进程所有时才显示工具条。不会预先清空剪贴板；复制成功会把所选文字留在剪贴板，不自动恢复旧内容。取消手势或切换窗口会放弃迟到的结果。此设置会保存在本机，公开安装包默认关闭，Mac 不使用此功能。词典查询仍需点击工具条选项。

## v0.3.17 更多 Windows 应用（默认关闭）

用户可以主动启用“更多应用自动复制取词”，把同样的 Ctrl+C 确认方式用于 WPS、其他浏览器和更多前台 Windows 应用。该选项会覆盖剪贴板，设置在本机保存；公开安装包默认关闭。终端、密码管理器、锁屏进程及可识别的原生密码编辑框不探测。只确认本次复制的新内容，不把后台剪贴板变化或单纯拖动当作选词，也不自动联网查词。

WPS 等多进程应用的剪贴板提供者可通过同一安装目录与直接父子进程关系确认；只在进程号或窗口归属不一致时做本机进程元数据核验，不上传进程列表或文件路径。
