Mac 首次运行指南

先核对下载，再处理系统提示。

当前版本未取得 Developer ID 签名及 Apple 公证。不是所有人都需要运行终端命令；成功后无需重复。

01核对来源与 SHA-256

  1. 只从本项目 GitHub Releases下载。Apple 芯片选择 arm64，Intel 选择 x64。
  2. 打开“终端”，输入 shasum -a 256 （末尾保留空格），把下载的 DMG / PKG 拖入终端，按回车。
  3. 将输出的 64 位值与同一 Release 的 SHA256SUMS.txt 对应文件逐字比较。不一致请停止并重新下载。校验一致不等于 Apple 安全认证。
  4. 把 WoerTranslator.app 安装到“应用程序”。默认路径为 /Applications/WoerTranslator.app。

02根据提示选择处理方式

“无法验证开发者 / 无法检查恶意软件”：确认来源可信且文件未遭修改后，先尝试打开 App，再到系统设置 → 隐私与安全性 → 仍要打开，阅读并确认系统提示。具体文字随系统版本变化。

“App 已损坏”：也可能是下载损坏、签名异常或文件被修改。先重新下载并核对校验值，仍有问题请反馈。

“将损坏你的电脑 / 检测到恶意软件 / 已移到废纸篓”：请停止运行，不要用下方命令跳过警告。

依据：Apple：在 Mac 上安全地打开 App。这些提示不能一概解释为“没有缴纳开发者费用”。

03可选终端操作

仅在确认可信、确为隔离拦截时使用。先退出 App，再打开“终端”。下面的一整行只针对这一份 App：

sudo xattr -rd com.apple.quarantine "/Applications/WoerTranslator.app"

此命令请求管理员权限，移除 App 内部的下载隔离标记，会改变这一份 App 的首次运行检查行为。它不修复文件、不提供公证，也不关闭系统整体保护。输入 Mac 本机密码时不显示字符是正常现象。

  • 成功时通常没有输出，再打开一次 App 即可。不需要运行第二次。
  • No such file or directory：检查安装路径和名称。自行改名或移动过 App 时，使用实际路径，并保留英文双引号。
  • 出现权限或其他错误请记录并反馈。不要反复执行，不要把路径扩大为整个应用程序、下载或系统目录，也不要关闭系统保护。

打开后：按需开启划词

右上角“···”可重新打开本指南。划词需要辅助功能和输入监控权限；未授权仍可手动输入或主动复制查询。自动朗读默认关闭。

本指南、复制按钮和 App 均不会自动执行上述命令或自动获取管理员权限。
