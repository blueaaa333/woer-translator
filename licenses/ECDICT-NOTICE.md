# ECDICT public data source

This project builds its offline English-Chinese `words.db` from `ecdict.csv` in
[skywind3000/ECDICT](https://github.com/skywind3000/ECDICT), pinned to commit
[`39cfb9672c0906b63569e0453c2e6abfb9ab182a`](https://github.com/skywind3000/ECDICT/commit/39cfb9672c0906b63569e0453c2e6abfb9ab182a).
The source file is 66,009,548 bytes with SHA-256
`d1ecbdf9ee2b920afb6f430ca6b6bb9f559588cf0dff86e04bd255f9390843cc`.

The upstream repository provides an MIT license; its complete text is retained
in `ECDICT-MIT.txt`. The upstream README describes historical inputs and
contributions including EDictAZ, exam vocabulary lists, cdict and BNC. This
notice records the upstream license and source used by this build; it does not
claim an independent, item-by-item audit of every historical contribution.

This database is separate from private ECDICT copies, personal exam lists and
PDF-derived data. None of those local materials were used to build or publish
this dictionary. The generated database is an adaptation of the pinned public
CSV; its build manifest records the source, database and gzip checksums.
