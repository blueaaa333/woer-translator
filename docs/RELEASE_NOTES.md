沃尔翻译官 v0.3.0：新增软件内更新提醒、后台下载、SHA-256 校验和“重启并更新”。右上角“···”可手动检查更新，也可关闭默认开启的每日自动检查。

**旧版本需要先手动安装本版一次。** v0.2.2 及更早版本没有更新检查功能，无法收到新加的提醒；安装 v0.3.0 后，后续版本才能通过软件内入口更新。应用不会自动强制下载或安装。

Mac 用户请先把 App 拖入 Applications，再从“应用程序”打开。用户点击“重启并更新”后，安装助手会准备新 App，退出旧版后替换并启动；复制或替换失败时保留或恢复旧版。安装位置需要当前账户可写。系统安全确认和划词权限仍需本人处理，更新不清除隔离标记，也不绕过 Apple 验证。

Windows 使用正式安装器更新，并在安装完成后重新打开软件；不强制重启电脑。更新保留用户目录中的设置、生词本和已下载的语音。

延续 v0.2.2 的 Mac 划词与卡顿修正：将系统监听、剪贴板及取词移到独立进程，避免系统调用迟滞拖住查词窗口。

Mac 工具条支持更多浏览器和可选中文本的应用。首次引导新增“启用 Mac 划词权限”按钮；授权辅助功能和输入监控后返回阅读页面重新选词。更新后若系统未沿用旧权限，请在系统设置中为 Applications 内的新版本重新授权，再退出并打开软件。

Apple 芯片和 Intel 构建均增加打包后真实启动检查：运行主事件循环、启动独立系统服务，并验证服务暂停时窗口仍有响应。自动检查不等同于已在所有实体 Mac 和浏览器上验收；仍欢迎反馈具体系统版本、浏览器和复现方式。

**Mac 用户请先看完 [首次运行指南](https://github.com/blueaaa333/woer-translator/blob/main/docs/MAC_FIRST_RUN.md)**。不要把“无法验证开发者”和“文件已损坏 / 检测到恶意软件”混为一谈。确认下载与 SHA-256 后，优先使用系统“仍要打开”入口；命令仅为可选手动操作，成功后不需要重复执行。

Mac 指南和海报可在仓库中查看，DMG 内也包含离线说明。首次成功打开后的引导可从右上角“··· → Mac 首次运行指南”重新查看。

### 下载选择

- Windows 10 / 11（64 位）：`Windows-x64-Setup.exe`。
- Mac Apple 芯片：`macOS-arm64.dmg`；Intel Mac：`macOS-x64.dmg`。打开后把 App 拖入 Applications。
- macOS 15 或更高版本为本次构建检查环境。较早版本尚未验证兼容性；Mac 版属首个预览版本，欢迎提供实际使用反馈。
- `SHA256SUMS.txt` 提供三个安装包的校验值，供手动核对或 Packages 下载器校验。构建报告、便携版及备用格式保留在 Actions 构建产物中；npm 包在 GitHub Packages 中提供。

### 使用说明

选中英文后显示小工具条，点击“查词”才读取选词并展开释义。也支持复制或手动输入查询；自动朗读默认关闭。

Windows 英美离线语音请在右上角“···”中主动选择下载，首次约 150 MB。安装包不附带 Piper 或模型。Mac 使用系统本地 `say`，分别选择 `en_GB` / `en_US` 口音；若系统缺少某一口音，会提示下载对应系统声音，绝不把同一个声音伪装成两种口音。

Mac 划词需在系统设置中授权辅助功能和输入监控；未授权时仍可手动或复制查询。请从菜单选择“启用 macOS 划词权限”。macOS 版没有在实体 Mac 上完成所有浏览器的划词体验验证，CI 检查不等同于完整人工验收。

### 签名与许可

Windows 安装器尚无商业代码签名；Mac App 仅作本地临时签名，没有 Apple Developer ID 签名和公证，系统可能拦截。请按系统官方说明和自己的信任判断处理，不需关闭系统整体安全保护。

原创代码 MIT；WordNet、COW、Wiktionary、Lucide、OpenCC、Python、Tcl/Tk 和 Mac 的 PyObjC 各适用其原许可。完整声明随程序资源提供，公开数据不包含个人 PDF 或 ECDICT。

### GitHub Packages

`@blueaaa333/woer-translator` 是 npm 安装包下载器，可自动选择平台并校验发行文件。普通用户直接下载上面的安装包即可，不需要 Node.js；npm 不会自动运行桌面程序。
