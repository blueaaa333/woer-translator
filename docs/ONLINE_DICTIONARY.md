# 在线维基词典

默认开启，可在“··· → 在线词典（维基词典）”关闭。仅在用户点击查词、按查询快捷键或手动搜索后，发送所查询的单词或短语；选中时只显示操作条，不读取页面全文。

先显示本地词库，再通过官方 Wikimedia API 查询中文维基词典；没有中文释义时，尝试英文维基词典的定义接口。英文版可能返回拉丁语等外来词，界面保留语言标记，不会将英文词形说明冒充中文翻译。它是在线词典，不是 GPT，也不是任意句子机器翻译。

接口超时、服务限流或网络不可达时会显示错误，不把连接失败当作没有收录；本地释义仍可使用。完整结果在本机缓存约一天，未收录结果缓存15分钟。缓存与用户查询记录不提交 GitHub。网络环境可能无法访问 Wikimedia，本软件不会绕过系统网络限制。

## 内容许可与署名

维基词典贡献者的文本依 CC BY-SA 4.0 使用。界面来源行明确标记在线维基词典和许可，点击“来源”可打开含原词条、作者编辑历史、查询版本及许可链接的本地署名页。提取 HTML 中的释义及繁简转换均已标明；这些修改后的词典文本仍依 CC BY-SA 4.0，而不是本项目的代码 MIT 许可。原网页存在额外署名或许可提示时，也应继续遵守。
